=====================================================
LORREY PROJECT - SINGLE APPLICATION (PORT 5173)
=====================================================

1. Frontend Application
Location: frontend/review-dashboard/UI2

Start Single Application (Port 5173):
cd frontend/review-dashboard/UI2
npm run dev

Access URL:
http://localhost:5173

=====================================================
2. Backend Service
Location: backend-node

Start Backend:
cd backend-node
npm run dev

(Note: If `npm run dev` fails with a nodemon permission error, run `npm start` directly)

=====================================================
3. AI-Worker Service
Location: ai-worker

Start AI-Worker:
cd ai-worker
source venv/bin/activate
uvicorn pipeline:app --reload
