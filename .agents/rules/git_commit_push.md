# Automatic Commit and Push Guidelines

Whenever you create, modify, refactor, or delete any file or code in this repository:
1. Stage the relevant modified files (`git add ...`).
2. Create a clean commit with a descriptive, professional message explaining what was changed and why (e.g. `feat(...)`, `fix(...)`, `refactor(...)`, or `docs(...)`).
3. Push the commits to the `main` branch across all configured remotes (`git push origin main && git push myrepo main && git push lorrey main`).
